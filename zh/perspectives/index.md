# 偏好是什么？ {#sec-part-perspectives}

所有偏好方法都假定：回路中的人具有预先存在、有待发现的偏好，而一次比较是对这一偏好的带噪声读数。其他学科检验这一假定已有一个世纪。心理学测量判断如何随情境、注意和提问顺序而变化，并考察哪些著名效应经受住了复现。神经科学研究价值如何计算、一次选择需要多长时间。经济学将显示偏好形式化，随后发现有人拒绝选择，或有意随机选择。哲学追问：系统何时可以正当地改变一个人的意愿。

设立本部分，是出于本书的论点：算法已趋成熟，悬而未决的是测量问题，即一次比较究竟测量了什么，以及提问本身如何影响回答者（@sec-preface-argument）。这些问题早有研究，只是不以优化为名。每章报告一个学科的证据，着眼于它对构建或评估偏好系统的人有何启示，最后说明它对比较建模的意义。有几处，读者可以亲自检验某个效应。

本部分以 @sec-comparisons 为前提；各章可以单独阅读。
